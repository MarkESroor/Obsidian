## Process this inbox

For each item, choose one:

- Delete it if it is no longer useful.
- Move knowledge to a project, area, or resource note.
- Turn an action into a task using **Tasks: Create or edit task**.
- Leave it here only if it still needs clarification.

Try to process this page once per day. It does not need to remain empty at all times.
