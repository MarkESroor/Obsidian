# Inbox

New loose notes land in `0 Inbox` automatically. Use today's daily note for quick thoughts; use this page or a new note for longer captures and shared links.

## Loose notes to sort

```query
path:"0 Inbox/" -path:"0 Inbox/Inbox.md"
```

## Sort in five minutes

- Action: make it a checkbox, write a concrete next step, and add `#next`, `#waiting`, or `#someday`.
- Useful idea: add `#idea` and, when helpful, a link such as `[[VRMasters]]`.
- Note with a clear home: on Windows, `Ctrl+M` moves the current note into a project, area, or resource folder.
- Part of a note: select it, press `Ctrl+Shift+E`, and choose a destination note. The extracted text is replaced with a link.
- No longer useful: discard it during review.
