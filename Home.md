## Needs attention

Real deadlines and planned work for today or earlier. Waiting tasks remain visible here when their dates need attention.

```tasks
not done
(due before tomorrow) OR (scheduled before tomorrow)
sort by due
sort by priority
limit 10
```

## Ready next actions

Choose up to three to focus on. Add `#next` to a task when it is ready to do; keep waiting and someday tasks out of this list.

```tasks
not done
tags include #next
tags do not include #waiting
tags do not include #someday
(no start date) OR (starts before tomorrow)
(no scheduled date) OR (scheduled before tomorrow)
sort by priority
sort by due
limit 10
```

## Keep the system moving

- **Daily, 5 minutes:** open [[Tasks#Needs sorting|Needs sorting]], clarify today's captures, and choose the next actions.
- **Weekly, 15 minutes:** review [[Ideas]], waiting tasks, and active projects. Each active project needs one concrete next action.
- Use a due date for a real deadline. Use a scheduled date for a day you plan to work.

Tasks queries exclude `4 Archive` and `6 Templates` through the Tasks plugin's global query. Checkboxes can be completed directly in these lists; the original note updates.
