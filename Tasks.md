# Tasks

This page is generated automatically from every open task in the vault. Edit the original task or use **Tasks: Create or edit task** from the command palette.

Tasks are sorted by **deadline first**, then by **priority** when they have the same deadline.

## Overdue

```tasks
not done
due before today
path does not include 4 Archive
path does not include 6 Templates
sort by due
sort by priority
group by due
```

## Due today

```tasks
not done
due today
path does not include 4 Archive
path does not include 6 Templates
sort by priority
sort by path
```

## Upcoming deadlines

```tasks
not done
due after today

path does not include 6 Templates
sort by due
sort by priority

```

## No deadline

```tasks
not done
no due date
path does not include 4 Archive
path does not include 6 Templates
sort by priority
sort by path
```
